# Exercises for lesson #18 Javascript

1. Створіть клас із назвою `Calculator`.
- У конструкторі класу ініціалізуйте властивість `result` початковим значенням `0`.
- Оголосіть у класі методи для виконання основних арифметичних операцій: `add()`, `subtract()`, `multiply()`, `divide()`. Ці методи повинні приймати два параметри та записувати результат відповідної арифметичної операції (згідно з назвою методу) у властивість `result` об'єкта.
- Методи повинні повертати отриманий результат, якщо передано лише одне значення, використовуйте поточне значення `result` об'єкта як перший операнд операції.
- Оголосіть метод `displayResult()`, який виводитиме в консоль (`console.log`) значення властивості `result` об'єкта.
- Перевірте свою роботу: створіть екземпляр класу (використовуючи конструктор) і викличте деякі з методів калькулятора.
