# Exercises for lesson #25 TypeScript

1. маємо функцію `concatName`, реалізація якої приймає два рядкові параметри: `first` (ім’я) та `last` (прізвище).

Якщо прізвище не передано, функція повертає лише ім’я. В іншому випадку вона повертає результат об’єднання імені та прізвища:


```js
const concatName = (first: string, last: string) => {
  if (!last) {
    return first;
  }

  return `${first} ${last}`;
};
```

Під час виклику `concatName` з ім’ям та прізвищем функція працює належним чином, без помилок:
```js
const result = concatName("John", "Doe");
```

Однак, якщо викликати `concatName` лише з ім’ям, виникає помилка:
```js
const result2 = concatName("John");

// Expected 2 arguments, but got 1.
```

Спробуйте використати анотацію необов’язкового параметра, щоб виправити помилку.


2. маємо функцію `concatTwoStrings`, яка приймає два параметри — `a` та `b` — і повертає рядок.

```js
const concatTwoStrings = (a, b) => {
// Parameter 'b' implicitly has an 'any' type.
// Parameter 'a' implicitly has an 'any' type.
  return [a, b].join(" ");
};

```

Результат виклику функції concatTwoStrings з аргументами «Hello» та «World» і перевірки того, чи є отримане значення рядком, не виявляє жодних помилок:

Наразі виникають помилки щодо параметрів `a` та `b`, для яких не було вказано типи.

Ваше завдання — додати анотації до параметрів функції `concatTwoStrings`, щоб усунути помилки.


3. маємо функцію, яка приймає два булеві параметри a та b і повертає a + b: 
```ts
const add = (a: boolean, b: boolean) => {
  return a + b;
// Operator '+' cannot be applied to types 'boolean' and 'boolean'.
};
````
- Наразі в коді є кілька помилок, позначених червоними хвилястими лініями.
- Перша з них — у рядку повернення функції `add`, де ми маємо `a + b`:
- Оператор «+» не можна застосовувати до типів «boolean» і «boolean».
- Також є помилка під першим аргументом у виклику функції `add`:
- Аргумент типу «number» не можна призначити параметру типу «boolean».
- Нарешті, ми бачимо помилку в результаті тесту, оскільки тип змінної `result` наразі визначено як `any`, що не збігається з типом `number`.

Ваше завдання — подумати, як змінити типи, щоб усунути помилки та гарантувати, що `result` матиме тип `number`. 


4. є функція `modifyUser`, яка приймає масив користувачів, ідентифікатор користувача, якого ми хочемо змінити, а також функцію `makeChange`, яка виконує цю зміну:
```ts
type User = {
  id: string;
  name: string;
};

const modifyUser = (user: User[], id: string, makeChange) => {
// Parameter 'makeChange' implicitly has an 'any' type.
  return user.map((u) => {
    if (u.id === id) {
      return makeChange(u);
    }

    return u;
  });
};

````
Наразі в `makeChange` є помилка.

Ось приклад того, як можна викликати цю функцію:
```ts
const users: User[] = [
  { id: "1", name: "John" },
  { id: "2", name: "Jane" },
];

modifyUser(users, "1", (user) => {
// Parameter 'user' implicitly has an 'any' type.
  return { ...user, name: "Waqas" };
});

````
параметр `user` у функції обробки помилок також викликає помилку «implicit any» (неявний тип `any`).

Необхідно оновити анотацію типу `modifyUser` для функції `makeChange`. Вона має повертати змінений об'єкт користувача. Наприклад, ми не повинні мати змогу встановити значення `123` для поля `name`, оскільки в типі `User` властивість `name` визначена як рядок (`string`):
```ts
modifyUser(
  users,
  "1",
  // @ts-expect-error
  (user) => {
    return { ...user, name: 123 };
  },
);
````
Як би ви визначили тип для функції `makeChange`, яка приймає об'єкт `User` і повертає об'єкт `User`?
