# Exercises for lesson #30 TypeScript

1. Створіть файл mathUtils.ts.
- У ньому опишіть та експортуйте дві функції:
  • add(a: number, b: number): number — повертає суму чисел.
  • subtract(a: number, b: number): number — повертає різницю чисел.
- Створіть файл main.ts.
- Імпортуйте обидві функції з mathUtils.ts та викличте їх, вивівши результат у консоль.


2. Створіть файл User.ts.
- Створіть та експортуйте за замовчуванням (default) клас User. Клас повинен мати конструктор, який приймає name: string, і метод greet(): string, що повертає «Привіт, я [name]».
- Створіть файл analytics.ts.
- Експортуйте з нього функцію log(message: string): void.
- Створіть файл app.ts.
- Імпортуйте клас User (оскільки це default, виберіть будь-яке ім'я при імпорті).
- Імпортуйте функцію log, але перейменуйте її під час імпорту (аліас) на logger.
- Створіть екземпляр користувача та запишіть його привітання за допомогою logger.

3. Створіть файл types.ts.
- Опишіть та експортуйте інтерфейс Product, який має поля: id: number, title: string, price: number.
- Створіть файл order.ts.
- Імпортуйте інтерфейс Product, використовуючи синтаксис import type.
- Створіть та експортуйте функцію calculateTotal(products: Product[]): number.
- Перевірте роботу в index.ts.

4. Створіть папку services.
- Всередині папки створіть три файли:
  • auth.ts -> експортуйте функцію login()
  • database.ts -> експортуйте функцію connectDb()
  • index.ts -> цей файл повинен реекспортувати усе з auth.ts та database.ts в один рядок для кожного файлу (використовуйте export * from ...).
- У корені проекту (поруч із папкою services) створіть файл server.ts і імпортуйте login та connectDb всього з одного шляху: ./services.
