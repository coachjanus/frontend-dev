# Exercises for lesson #31 TypeScript

1. Створіть нову папку проекту та ініціалізуйте її: npm init -y.
2. Встановіть Webpack: npm install --save-dev webpack webpack-cli style-loader css-loader.
3. Створіть таку структуру папок:
├── src/
│   ├── index.js
│   └── style.css
├── index.html
└── webpack.config.js

4. У файлі style.css додайте просте правило: body { background-color: lightblue; }.
5. У файлі index.js імпортуйте цей CSS файл.
6. Налаштуйте webpack.config.js, щоб він обробляв .css завантажувачами style-loader та css-loader.
7. Зберіть проект за допомогою команди webpack --mode production.
8. Підключіть готовий файл dist/index.js до вашого index.html та відкрийте сторінку в браузері. Фон має стати блакитним.
