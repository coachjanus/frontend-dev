# Exercises for lesson #37 Angular

Вправа 1: Створити картку користувача-розробника.

1. Компонент (.ts): Створіть такі властивості у класі компонента:
username = 'Олексій';
role = 'Frontend Developer';
avatarUrl = 'https://angular.dev';
isLoggedIn = true;


2. Шаблон (.html): Створіть шапку сайту (Header). Якщо змінна isLoggedIn має значення true, відобразіть привітання «Вітаємо, Олексію!» та кнопку «Вийти». Якщо false — відобразіть кнопки «Увійти» та «Зареєструватися».
