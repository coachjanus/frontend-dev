# Exercises for lesson #15 Javascript

1. Напишіть код, виконавши завдання з кожного пункту окремим рядком:
    Створіть порожній об’єкт user.
    Додайте властивість name зі значенням Іван.
    Додайте властивість surname зі значенням Сміт.
    Змініть значення name на Петро.
    Видаліть властивість name з об’єкта.

2. Напишіть функцію isEmpty(obj), яка повертає true, якщо об’єкт не має жодної властивості, інакше false.

Має так працювати:


```js
let schedule = {};

alert( isEmpty(schedule) ); // true

schedule["8:30"] = "Вставай";

alert( isEmpty(schedule) ); // false
````
    Використовуючи цикл for вивести на консоль парні елементи з масиву Numbs.

3. У нас є об’єкт для зберігання заробітної плати нашої команди:
```js
let salaries = {
  John: 100,
  Ann: 160,
  Pete: 130
}
```
Напишіть код для підсумовування всіх зарплат і збережіть у змінній sum. У наведеному вище прикладі має бути 390.

Якщо об’єкт salaries порожній, то результат має бути 0.

4. Помножте числові значення властивостей на 2. Створіть функцію multiplyNumeric(obj), яка примножує всі числові властивості об’єкта obj на 2.

Наприклад:
```js
// до виклику функції
let menu = {
  width: 200,
  height: 300,
  title: "Моє меню"
};

multiplyNumeric(menu);

// після виклику функції
menu = {
  width: 400,
  height: 600,
  title: "Моє меню"
};
```
функції multiplyNumeric не потрібно нічого повертати. Слід безпосередньо змінювати об’єкт.

Використовуйте typeof для перевірки, що значення властивості числове.
