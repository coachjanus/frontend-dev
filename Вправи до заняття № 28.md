# Exercises for lesson #28 TypeScript

1. Базове наслідування та виклик super()

Завдання

1. Створіть батьківський клас Worker (Працівник), який має:
  • Властивість name: string (публічна).
  • Конструктор, який ініціалізує name.
  • Метод work() повертає рядок: "{name} працює.".
2. Створіть дочірній клас Developer (Розробник), який наслідує Worker:
  • Додайте нову властивість programmingLanguage: string.
  • В конструкторі прийміть name та programmingLanguage, викликавши конструктор батька через super(name).
  • Перевизначте (переважно використавши чи доповнивши) метод work(), щоб він повертав: "{name} пише код на {programmingLanguage}.".


2. Використання super.method()

Завдання

1. Створіть базовий клас Rectangle (Прямокутник):
  • Властивості: width: number, height: number.
  • Метод getArea(): number, що повертає площу (width * height).
2. Створіть дочірній клас Square (Квадрат), який наслідує Rectangle:
  • Квадрат має лише одну сторону side: number.
  • В конструкторі викличте super(side, side).
  • Додайте метод describe(), який повертає рядок із викликом батьківського методу площі, наприклад: "Квадрат зі стороною X має площу Y", де площу отримано через звернення до логіки чи базового класу.


3. Модифікатори доступу та наслідування (protected)


Завдання

1. Створіть базовий клас BankAccount (Банківський рахунок):
  • Захищена властивість (protected) balance: number.
  • Конструктор для ініціалізації початкового балансу.
  • Метод deposit(amount: number): void, який додає кошти до балансу.
2. Створіть дочірній клас SavingsAccount (Ощадний рахунок), який наслідує BankAccount:
  • Додайте метод addInterest(rate: number): void, який нараховує відсотки на balance (наприклад: this.balance += this.balance * (rate / 100)).
  • Додайте метод getBalance(): number, що повертає поточний balance (оскільки balance є protected, він доступний всередині класу-нащадка, але закритий ззовні).
