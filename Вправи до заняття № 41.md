# Exercises for lesson #41 Angular

Вправа 1: Створіть компонент app-custom-counter. 

Створіть модель (вхідне значення за замовчуванням: 0)

```ts
// Оголошуємо модель (вхідне значення за замовчуванням: 0)

count = model<number>(0);
```
Використовуйте template:

```ts
template: `<div>
     <p>Поточне значення: {{ count() }}</p>
     <button (click)="increment()">Збільшити (+1)</button>
   </div> `



 increment() {
   // Оновлюємо значення сигналу. Батьківський компонент автоматично дізнається про зміни!
   this.count.update(value => value + 1);
 }
}
```

У батьківському компоненті зв'яжіть модель як із звичайним сигналом, так і з простою змінною, використовуючи синтаксис «банана в коробці» 

```ts
[(count)]="parentCount"


parentCount = signal(10); // Початкове значення
```

Використовуйте template:

 ```html
 template: `<h3>Батьківський компонент (значення: {{ parentCount() }})</h3>
 
 <!-- Двостороннє зв'язування з сигналом -->
 <app-custom-counter [(count)]="parentCount"></app-custom-counter> `

 ```
