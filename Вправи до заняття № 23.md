# Exercises for lesson #23 TypeScript

1. Налаштування середовища розробки для TypeScript: 
- Завантажте та встановіть офіційну версію Node.js.
- Встановіть TypeScript як залежність для розробки (devDependencies)
- Створіть файл конфігурації tsconfig.json
- Встановіть ESLint пакет typescript-eslint
- Встановіть Prettier
- Встановіть Vitest
- Додайте скрипти автоматизації у файл package.json:
    - скрипт dev: запускає проєкт у режимі розробки. 
    - скрипт build: компілює фінальну (production) версію коду в папку dist.
    - скрипт start: запускає вже скомпільований JavaScript (використовується на сервері).
