# Exercises for lesson #20 Javascript

1. Створіть файли login.html, login.css та login.js. 

- Всередині файлу login.html створити модальну форму входу на сайт  
- Форма має містити такі поля
    - Логін або 
    - Пароль
    - Прапорець Запам'ятати мене
- Стилізуйте форму, використовуючи стилі форми реєстрації
- Використовуючи подію DOMContentLoaded, перевірте, чи користувач вже авторизований (при завантаженні сторінки)
- Додайте кнопку закриття модального вікна
- Додайте поля форми Увійти та Відмінити
