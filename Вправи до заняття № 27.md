# Exercises for lesson #27 TypeScript

1: Створіть інтерфейс User, який описує об'єкт користувача.
Умови:
1. Обов'язкові поля: id (число), name (рядок), email (рядок).
2. Необов'язкове поле: phoneNumber (рядок).
3. Поле, яке можна лише читати (readonly): createdAt (дата або рядок).
4. Створіть змінну myUser, яка реалізує цей інтерфейс, та спробуйте змінити їй id або createdAt, щоб побачити помилку компілятора.

2: Напишіть інтерфейс для функції фільтрації масиву.
Умови:
1. Створіть інтерфейс StringFilterFn, який описує функцію. Ця функція має приймати два аргументи: масив рядків (array) та рядок-критерій (criterion). Функція повинна повертати новий масив рядків.
2. Створіть функцію filterLength, яка відповідає цьому інтерфейсу. Вона має повертати лише ті рядки, довжина яких більша за число, передане у criterion (перетворіть його всередині функції на число).
