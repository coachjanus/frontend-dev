3. Створіть функцію first, яка повертає первый элемент любого массива и null, если он пустой:
```ts
function first<T>(coll: Array<T>): T | null {
  return coll[0] ?? null;
}

first([]); // null
first([3, 2]); // 3
first(["code-basics", "hexlet"]); // code-basics
````
