# Exercises for lesson #26 TypeScript

1. є клас під назвою `CanvasNode`, який наразі працює так само, як і порожній об'єкт:
```ts
class CanvasNode {}
```

У межах тестового сценарію ми створюємо екземпляр цього класу, викликаючи `new CanvasNode()`.

Однак виникають помилки, оскільки ми очікуємо, що в ньому будуть дві властивості — `x` та `y`, — кожна з яких має значення за замовчуванням, що дорівнює 0:
```ts
it("Should store some basic properties", () => {
  const canvasNode = new CanvasNode();

  expect(canvasNode.x).toEqual(0);
// Property 'x' does not exist on type 'CanvasNode'.
  expect(canvasNode.y).toEqual(0);
// Property 'y' does not exist on type 'CanvasNode'.

  // @ts-expect-error Property is readonly
  canvasNode.x = 10;

  // @ts-expect-error Property is readonly
  canvasNode.y = 20;
});
```

Як можна зрозуміти з директив `@ts-expect-error`, ми також очікуємо, що ці властивості будуть доступні лише для читання (`readonly`).

Ваше завдання — реалізувати клас `CanvasNode` так, щоб він відповідав цим вимогам. Для додаткової практики виконайте це завдання двома способами: з використанням конструктора та без нього.


2. клас CanvasNode не має властивостей, доступних лише для читання:
```ts
class CanvasNode {
  x = 0;
  y = 0;
}
```

Існує тестовий сценарій для перевірки можливості переміщення об'єкта CanvasNode у нове місце:
```ts
it("Should be able to move to a new location", () => {
  const canvasNode = new CanvasNode();

  expect(canvasNode.x).toEqual(0);
  expect(canvasNode.y).toEqual(0);

  canvasNode.move(10, 20);
// Property 'move' does not exist on type 'CanvasNode'.

  expect(canvasNode.x).toEqual(10);
  expect(canvasNode.y).toEqual(20);
});

```

Наразі виникає помилка під час виклику методу `move`, оскільки в класі `CanvasNode` такий метод відсутній.

Ваше завдання — додати до класу `CanvasNode` метод `move`, який оновлюватиме властивості `x` та `y`, встановлюючи нове розташування.



3. клас CanvasNode має конструктор, що приймає необов’язковий аргумент (position). Цей аргумент position є об’єктом, який замінює окремі координати x та y, що використовувалися раніше:
```ts
class CanvasNode {
  x: number;
  y: number;

  constructor(position?: { x: number; y: number }) {
    this.x = position?.x ?? 0;
    this.y = position?.y ?? 0;
  }

  move(x: number, y: number) {
    this.x = x;
    this.y = y;
  }
}
```

У цих тестових випадках виникають помилки під час звернення до властивості position, оскільки наразі вона не є властивістю класу CanvasNode:
```ts
it("Should be able to move", () => {
  const canvasNode = new CanvasNode();

  expect(canvasNode.position).toEqual({ x: 0, y: 0 });
// Property 'position' does not exist on type 'CanvasNode'.

  canvasNode.move(10, 20);

  expect(canvasNode.position).toEqual({ x: 10, y: 20 });
// Property 'position' does not exist on type 'CanvasNode'.
});

it("Should be able to receive an initial position", () => {
  const canvasNode = new CanvasNode({
    x: 10,
    y: 20,
  });

  expect(canvasNode.position).toEqual({ x: 10, y: 20 });
// Property 'position' does not exist on type 'CanvasNode'.
});
```

Ваше завдання — оновити клас CanvasNode, додавши в нього метод отримання позиції (getter), який дозволить успішно пройти тестові сценарії.

4. Клас CanvasNode було оновлено: тепер x та y є приватними властивостями:
```ts
class CanvasNode {
  #x: number;
  #y: number;

  constructor(position?: { x: number; y: number }) {
    this.#x = position?.x ?? 0;
    this.#y = position?.y ?? 0;
  }

  // your `position` getter method here

  // move method as before
}
```

Символ `#` перед властивостями `x` та `y` означає, що вони доступні лише для читання (readonly) і їх не можна змінювати безпосередньо за межами класу. Крім того, якщо визначено лише геттер (getter) без сеттера (setter), така властивість також вважатиметься доступною лише для читання:
```ts
canvasNode.position = { x: 10, y: 20 };
// Cannot assign to 'position' because it is a read-only property. - Не вдається присвоїти значення властивості 'position', оскільки вона доступна лише для читання.
````

Ваше завдання — написати сеттер для властивості `position`, завдяки якому цей приклад успішно виконуватиметься.
