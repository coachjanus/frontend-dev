# Exercises for lesson #36 Angular

Вправа 1: Створити картку користувача-розробника.

1. Компонент (.ts): Створіть такі властивості у класі компонента:
username = 'Олексій';
role = 'Frontend Developer';
avatarUrl = 'https://angular.dev';
isOnline = true;
skillsCount = 5;

2. Шаблон (.html):
  • Виведіть username, role та загальну кількість навичок 
  • Виведіть кількість навичок skillsCount, помноживши skillsCount на 2.
  • Прив'яжіть avatarUrl до атрибута src тегу <img>. 
  • Створіть кнопку «Надіслати повідомлення». Прив'яжіть властивість disabled кнопки «Надіслати повідомлення», якщо isOnline === false.
